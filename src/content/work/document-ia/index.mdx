Document IA nace de un problema concreto: cientos de facturas y comprobantes que terminan a mano en una planilla. La aplicación toma esos documentos, los lee con inteligencia artificial y devuelve los datos ya ordenados en Excel.

## Mi rol

Me encargué del producto completo: modelo de datos, flujo de carga y procesamiento, integración con la API de Gemini, pantalla de revisión y generación del Excel. También definí las plantillas, que son la pieza que hace flexible al sistema: cada usuario arma la suya con los campos que necesita.

## Stack

- **Frontend:** Next.js 16 (App Router), React 19, Tailwind CSS 4 y TypeScript.
- **Backend:** Supabase (Auth, PostgreSQL con RLS), Cloudflare R2 para archivos privados, API de Gemini para extracción estructurada y un worker en Node para el procesamiento asíncrono.
