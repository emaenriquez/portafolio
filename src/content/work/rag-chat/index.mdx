RAG Chat es una aplicación Full Stack que permite subir documentos y mantener conversaciones contextuales con IA mediante Retrieval-Augmented Generation (RAG).

## Stack

- **Frontend:** React.js, React Router, Tailwind CSS y Vite.
- **Backend:** Node.js, Express 5, TypeScript, Prisma 7, PostgreSQL + pgvector, Google Generative AI (Gemini), Cloudflare R2, Swagger y Zod.

**Estado:** Beta.
